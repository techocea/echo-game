\# ECHO



\*\*An atmospheric 2D story-driven puzzle-platformer built with Godot 4.\*\*



ECHO is an indie game project exploring a mysterious, deserted world through environmental storytelling, platforming, and a unique mechanic called \*\*Echo Pulse\*\*.



You play as Eli, who awakens in an abandoned world and encounters a mysterious voice known as Echo. As Eli explores the environment, the connection between them begins to unfold.



\## 🎮 Game Overview



\- \*\*Genre:\*\* 2D Platformer / Puzzle / Story-Driven Adventure

\- \*\*Engine:\*\* Godot 4

\- \*\*Language:\*\* GDScript

\- \*\*Platform:\*\* PC (initial development target)

\- \*\*Project Status:\*\* Early Prototype



\## ✨ Features



\### Implemented

\- Player movement and jumping

\- Physics-based movement and gravity

\- Platform collisions

\- Hidden platforms

\- Echo Pulse input for revealing hidden platforms

\- Temporary platform reveal mechanic

\- Basic expanding cyan pulse visual effect



\### Planned

\- Reveal platforms only within the Echo Pulse radius

\- Improved pulse animations and visual effects

\- Atmospheric environments and lighting

\- Environmental puzzles

\- Sound design and music

\- Story progression and narrative reveals

\- Character and environment art

\- Multiple levels

\## 🚀 Getting Started



\### Requirements

\- Godot 4.x

\- Git (optional, for cloning the repository)



\### Run Locally



1\. Clone this repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/YOUR-USERNAME/echo-game.git

&#x20;  ```



2\. Open Godot Engine.

3\. Import the project by selecting the cloned folder containing `project.godot`.

4\. Open the project and run the main scene.



During early development, you may need to run `Level01.tscn` directly from the editor.
