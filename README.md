# ECHO

An atmospheric 2D story-driven puzzle-platformer built with Godot 4.

## About the Game

Eli awakens in a deserted world and encounters a mysterious voice
known as Echo. Explore the world, solve puzzles, and uncover
the connection between them.

## Features

- Player movement and jumping
- Physics-based platforming
- Hidden platforms
- Echo Pulse mechanic

## Built With

- Godot 4
- GDScript
- Git and GitHub

## Controls

| Action | Key |
|---|---|
| Move left | A / Left Arrow |
| Move right | D / Right Arrow |
| Jump | Space |
| Echo Pulse | E |

## Project Status

Early prototype — active development.
